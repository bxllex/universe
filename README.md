# 🌌 ดาวดวงเดียวกัน — วิธีเอาขึ้น GitHub Pages

ในชุดนี้มี 3 ไฟล์ (ต้องอยู่ **โฟลเดอร์เดียวกัน** เสมอ):

- `index.html` — หน้าหลัก (แผนที่ดาว + ล็อกรหัส)
- `universe.html` — ดาวดวงเดียวกัน (เรื่องราว 6 บท + ดาว AI)
- `rest.html` — มุมพักใจของหนู (ไว้ให้แฟนหายเหนื่อย)
- `planet.html` — ดาวเคราะห์ของเรา (หมุน สำรวจ ปลูกดาวสะสม)
- `mu.html` — เสี่ยงทายกับดาว (สำหรับสายมู: ไพ่/ดูดวง/ขอพร/ราศี)

> หน้าแรกคือ `index.html` เปิดมาต้องใส่รหัสก่อน (ค่าเริ่มต้น = **0815**)

---

## ✅ ก่อนอัปโหลด (แก้ได้ตามใจ)

เปิด `index.html` หาบล็อก `const HUB = {` ด้านบนของ `<script>`
- `password` — เปลี่ยนรหัสเข้าเว็บ
- `hint` — คำใบ้รหัส
- `stars[].x , y` — ขยับตำแหน่งดาวบนแผนที่

เปิด `universe.html` หาบล็อก `const CONFIG = {`
- `chapters` — แก้เนื้อเรื่องแต่ละบท
- `finaleSignature` — จดหมายตอนจบ
- `bgMusic` — `"ambient"` (ดนตรีบรรเลง) หรือ `"song"` (เพลง YouTube)

## 🚀 วิธีขึ้น GitHub Pages (ทำผ่านเว็บ ไม่ต้องใช้โปรแกรม)

1. ไปที่ **github.com** → กดปุ่ม **New** (สร้าง repository ใหม่)
2. ตั้งชื่อ repo เช่น `universe` → เลือก **Public** → กด **Create repository**
3. ในหน้า repo กด **Add file → Upload files**
4. ลากไฟล์ **`index.html`**, **`universe.html`**, **`rest.html`**, **`planet.html`** และ **`mu.html`** เข้าไป → กด **Commit changes**
5. ไปที่ **Settings → Pages**
6. หัวข้อ **Source** เลือก **Deploy from a branch**
   → **Branch:** `main` , โฟลเดอร์ `/ (root)` → กด **Save**
7. รอสัก 1–2 นาที เว็บจะอยู่ที่:
   ```
   https://bxllex.github.io/universe/
   ```
8. เปิดลิงก์นั้น → ใส่รหัส → เสร็จ! ✦

## 📌 ข้อควรรู้

- **รหัสเป็นแบบ soft lock** — กันคนทั่วไปได้ แต่คนที่กดดูซอร์สโค้ดจะเห็นรหัส (สำหรับของขวัญส่วนตัวมักพอ ยิ่งลิงก์เดายากยิ่งดี)
- **ดาว AI** บน GitHub Pages จะใช้ "คำตอบสำรอง" (อบอุ่นแต่ไม่ฉลาดสด) ถ้าอยากให้ตอบสดจริงต้องต่อ backend ทีหลัง
- **ห้องความทรงจำ** (imhere / lovebox / make-up) ลิงก์ไปเว็บเดิมของคุณอยู่แล้ว ไม่ต้องอัปซ้ำ
- อยากใช้ URL สวย ๆ ชื่ออื่น ก็แค่ตั้งชื่อ repo เป็นชื่อนั้น (เช่น repo `rao` → `bxllex.github.io/rao/`)
